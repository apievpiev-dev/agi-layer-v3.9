# 🚀 Быстрый старт

## Установка

```bash
# Установите зависимости
pip install -r requirements.txt

# Инициализируйте систему
python content_factory/main.py --mode init
```

## Запуск

### Веб-интерфейс (рекомендуется)

```bash
python content_factory/main.py --mode web
```

Откройте браузер: http://localhost:8502

### CLI режим

```bash
python content_factory/main.py --mode cli
```

## Первые шаги

1. **Создайте фундамент** (в веб-интерфейсе):
   - Добавьте цель (например, "Привлечение трафика")
   - Добавьте аудиторию (например, "Предприниматели 25-40 лет")
   - Добавьте тему (например, "Маркетинг")

2. **Соберите идеи**:
   - Перейдите в раздел "Планирование"
   - Выберите тему
   - Нажмите "Собрать идеи"
   - Одобрите лучшие идеи

3. **Создайте контент-план**:
   - Нажмите "Создать контент-план"
   - Система автоматически распределит идеи по датам

4. **Создайте ТЗ**:
   - Выберите запись из плана
   - Нажмите "Создать ТЗ"
   - Система сгенерирует техническое задание

5. **Произведите контент**:
   - Выберите ТЗ
   - Нажмите "Создать контент"
   - AI сгенерирует текст

6. **Проверьте качество**:
   - Перейдите в "Контроль качества"
   - Выберите контент
   - Нажмите "Проверить качество"
   - Исправьте замечания

7. **Опубликуйте**:
   - После одобрения перейдите в "Дистрибуция"
   - Выберите платформу
   - Опубликуйте контент

## Настройка AI моделей

По умолчанию система использует локальные бесплатные модели. Для улучшения качества можно:

1. Указать API ключи в `.env`:
   ```
   OPENAI_API_KEY=your_key_here
   YANDEX_GPT_API_KEY=your_key_here
   ```

2. Или использовать локальные модели (требуется больше ресурсов):
   - Модели загрузятся автоматически при первом использовании
   - Требуется ~5-10 ГБ свободного места

## Структура данных

Все данные хранятся в SQLite базе: `content_factory/data/content_factory.db`

Готовый контент сохраняется в: `content_factory/output/`

## Поддержка

При возникновении проблем проверьте:
- Установлены ли все зависимости
- Инициализирована ли база данных
- Доступны ли AI модели (или указаны API ключи)
