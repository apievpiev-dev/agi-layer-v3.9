# 🏭 Контент-завод

Автоматизированная система производства контента с полным циклом от планирования до аналитики.

## Описание

Контент-завод — это система, которая позволяет производить качественный контент регулярно, предсказуемо и в нужных объемах. Система включает 7 основных этапов производства:

1. **Планирование** - сбор идей, SEO-анализ, создание контент-плана
2. **Подготовка** - генерация технических заданий
3. **Производство** - создание контента с помощью AI
4. **Контроль качества** - проверка редактирования, корректуры, SEO, фактчекинга
5. **Упаковка** - создание обложек, инфографики, изображений для соцсетей
6. **Дистрибуция** - публикация на различных платформах
7. **Аналитика** - отслеживание метрик и генерация отчетов

## Установка

### Требования

- Python 3.8+
- SQLite3 (встроен в Python)

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Инициализация системы

```bash
python content_factory/main.py --mode init
```

## Использование

### Веб-интерфейс (рекомендуется)

```bash
python content_factory/main.py --mode web
```

Веб-интерфейс будет доступен по адресу: http://localhost:8502

### CLI режим

```bash
python content_factory/main.py --mode cli
```

## Настройка

Основные настройки находятся в `config/settings.py`:

- AI модели (локальные бесплатные модели)
- Форматы контента
- Настройки качества
- Платформы дистрибуции

## AI модели

Система поддерживает несколько бесплатных локальных моделей:

- **Текст**: microsoft/phi-2 (через transformers)
- **Эмбеддинги**: sentence-transformers/all-MiniLM-L6-v2
- **Изображения**: runwayml/stable-diffusion-v1-5 (опционально)

Также поддерживаются внешние API (если указаны ключи):
- OpenAI GPT
- Yandex GPT

## Рабочий процесс

1. **Фундамент**: Создайте цели, аудитории и темы
2. **Планирование**: Соберите идеи и создайте контент-план
3. **ТЗ**: Сгенерируйте технические задания для контента
4. **Производство**: Создайте контент с помощью AI
5. **Качество**: Проверьте и одобрите контент
6. **Упаковка**: Создайте обложки и изображения
7. **Дистрибуция**: Опубликуйте контент
8. **Аналитика**: Отслеживайте результаты
