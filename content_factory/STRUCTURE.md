## Модули производства

### 1. Planning (Планирование)
- Сбор идей из различных источников
- SEO-анализ
- Создание контент-плана
- Распределение по датам

### 2. Preparation (Подготовка)
- Генерация технических заданий
- Создание структуры контента
- Определение основных тезисов
- Извлечение ключевых слов

### 3. Production (Производство)
- Генерация контента с помощью AI
- Поддержка разных форматов (статьи, посты, видео)
- Улучшение структуры
- Сохранение в БД

### 4. Quality Control (Контроль качества)
- Проверка редактирования (логика, структура)
- Корректура (орфография, пунктуация)
- SEO-проверка
- Фактчекинг
- Общая оценка качества

### 5. Packaging (Упаковка)
- Создание обложек
- Генерация инфографики
- Изображения для соцсетей
- Иллюстрации (через AI)

### 6. Distribution (Дистрибуция)
- Публикация на различных платформах
- Планирование публикаций
- Переупаковка контента
- Отслеживание публикаций

### 7. Analytics (Аналитика)
- Отслеживание метрик
- Анализ производительности
- Топ-контент
- Генерация отчетов
- Рекомендации

## База данных

SQLite база данных с таблицами:
- `goals` - Цели
- `audiences` - Аудитории
- `topics` - Темы
- `content_ideas` - Идеи контента
- `content_plan` - Контент-план
- `content_specs` - Технические задания
- `content_items` - Готовый контент
- `quality_checks` - Проверки качества
- `design_assets` - Дизайн-ассеты
- `publications` - Публикации
- `analytics` - Аналитика

## AI Интеграция

Поддержка нескольких моделей:
- **Локальные** (бесплатные):
  - microsoft/phi-2 (текст)
  - sentence-transformers/all-MiniLM-L6-v2 (эмбеддинги)
  - runwayml/stable-diffusion-v1-5 (изображения, опционально)

- **Внешние API** (если указаны ключи):
  - OpenAI GPT
  - Yandex GPT

## Веб-интерфейс

Streamlit приложение с разделами:
- 📊 Дашборд
- 🎯 Фундамент (цели, аудитории, темы)
- 📅 Планирование
- 📝 ТЗ
- ✍️ Производство
- ✅ Контроль качества
- 🎨 Упаковка
- 📤 Дистрибуция
- 📈 Аналитика

## Запуск

```bash
# Инициализация
python content_factory/main.py --mode init

# Веб-интерфейс
python content_factory/main.py --mode web

# CLI режим
python content_factory/main.py --mode cli
```

## Расширение

Система легко расширяется:
- Добавление новых AI моделей в `ai_integration.py`
- Новые форматы контента в `production.py`
- Интеграция с новыми платформами в `distribution.py`
- Дополнительные проверки в `quality_control.py`
