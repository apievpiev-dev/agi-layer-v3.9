### 7 этапов производства

1. **Планирование** (`modules/planning.py`)
   - Сбор идей из разных источников
   - SEO-анализ
   - Создание контент-плана
   - Распределение по датам

2. **Подготовка** (`modules/preparation.py`)
   - Генерация технических заданий
   - Создание структуры контента
   - Определение тезисов
   - Извлечение ключевых слов

3. **Производство** (`modules/production.py`)
   - Генерация контента с AI
   - Поддержка форматов (статьи, посты, видео)
   - Улучшение структуры
   - Автоматическое сохранение

4. **Контроль качества** (`modules/quality_control.py`)
   - Проверка редактирования
   - Корректура
   - SEO-проверка
   - Фактчекинг
   - Общая оценка

5. **Упаковка** (`modules/packaging.py`)
   - Создание обложек
   - Генерация инфографики
   - Изображения для соцсетей
   - AI-иллюстрации

6. **Дистрибуция** (`modules/distribution.py`)
   - Публикация на платформах
   - Планирование публикаций
   - Переупаковка контента
   - Отслеживание

7. **Аналитика** (`modules/analytics.py`)
   - Отслеживание метрик
   - Анализ производительности
   - Топ-контент
   - Отчеты и рекомендации

## 🚀 Быстрый старт

```bash
# 1. Установите зависимости
pip install -r requirements.txt

# 2. Инициализируйте систему
python content_factory/main.py --mode init

# 3. Запустите веб-интерфейс
python content_factory/main.py --mode web
```

Откройте: http://localhost:8502
